01 / Question

Do methanol and n-heptane combustion measurements show different levels of unexplained variability under the tested conditions?

02 / Method

Clean and analyze NASA FLEX data using regression, variance-comparison tests, robust inference, and pressure-group cross-validation.

03 / Boundary

Statistical differences do not, by themselves, establish the physical mechanism. The dataset lacks direct soot measurements, and results are specific to the analyzed experiments.

02 / How I work

Better questions.

I’m interested in aerospace systems, aerodynamics, and computational modeling. What connects my projects is a preference for understanding assumptions and failure modes before trusting an elegant answer.
01 / FRAME

State the assumption.

What should the system do? Under which conditions? Which variables are measured, and which are only inferred?

02 / TEST

Put it against data.

Use simulations, experiments, or existing datasets. Measure error and variation instead of hiding them.

03 / REVISE

Explain the mismatch.

Distinguish evidence from interpretation, document limitations, and make the next test better.
